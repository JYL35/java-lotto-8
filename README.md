# 최종 코딩 테스트

---

## 📜 구현 기능 목록

### 구매 개수
- 구매 개수는 구매 금액을 받아와 개수를 계산한다.
- 받아온 구매 금액은 다음과 같은 유효성 검사를 받는다.
  - 1,000원 단위
  - 100,000원 이하

### 로또

- 로또는 로또 번호를 가진다.
- 로또는 다음과 같은 유효성 검사를 받는다.
  - 로또 번호 6개
  - 로또 번호 간 중복 X

### 로또 번호

- 로또 번호는 숫자 1개를 가진다
- 로또 번호는 다음과 같은 유효성 검사를 받는다.
  - 숫자는 1 ~ 45

### 당첨 번호
- 당첨 번호는 당첨 로또와 보너스 번호를 가진다.
- 당첨 로또는 로또와 동일한 유효성 검사를 받는다.
- 보너스 번호는 로또 번호와 동일한 유효성 검사를 받는다.
- 당첨 로또와 보너스 번호는 다음과 같은 유효성 검사를 받는다.
  - 당첨 로또와 보너스 번호 간의 중복 X

### 비즈니스 로직

- 구매 개수만큼 로또 발급
- 당첨 번호 발급
- 당첨 번호와 구매 로또 비교
  - 이후 당첨 내역 및 당첨금 계산
- 수익률 계산

### 입력 검증
- 구매 금액 검증 및 파싱
  - 빈 값
  - 숫자
- 당첨 번호 검증 및 파싱
  - 빈 값
  - 숫자
- 보너스 번호 검증 및 파싱
  - 빈 값
  - 숫자

### 입/출력

### 입력

- 구입 금액 입력
- 당첨 번호 입력
- 보너스 번호 입력

### 출력

- 발행 수량 출력
- 발행 로또 출력 (오름차순)
- 당첨 내역 출력 (5등부터 1등까지)
- 수익률 출력 (소수점 둘째 자리 반올림)

### ⚠️ 예외 처리

잘못된 값을 입력할 경우 `IllegalArgumentException`를 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.

- 유효성 검사 실패 시 예외 발생
